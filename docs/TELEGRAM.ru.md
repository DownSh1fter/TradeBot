# Telegram-уведомления

[English](TELEGRAM.en.md) · [Bybit Demo](REALTIME.ru.md)

Уведомления работают в `realtime-paper` и `bybit-demo`. Бот только отправляет сообщения в заданный чат; команд покупки/продажи через Telegram нет. Исторический бэктест не отправляет уведомлений.

## Создание Telegram-бота

1. В Telegram откройте проверенного **@BotFather**, отправьте `/newbot`, задайте имя и username. Сохраните полученный токен как пароль; не публикуйте его.
2. Откройте созданного бота и нажмите **Start** или отправьте `/start`.
3. Узнайте свой `chat_id`. Для личного чата можно использовать **@userinfobot**: его поле `Id` — ваш chat ID. Токен вашего бота этому сервису передавать не нужно. Для группы нужен ID группы, обычно отрицательный; добавьте своего бота в группу с правом отправки сообщений. Уведомления увидят все участники выбранного чата.

## Настройка на Mac (zsh)

В том же терминале VS Code, где будете запускать TradeBot:

```bash
read -s "TELEGRAM_BOT_TOKEN?Telegram bot token: "
export TELEGRAM_BOT_TOKEN
echo
export TELEGRAM_CHAT_ID='123456789'
export TELEGRAM_STATUS_SECONDS='300'
```

Замените `123456789` своим chat ID. Токен при вводе не отображается и не сохраняется в истории команд. Минимальный интервал сводки — 30 секунд, по умолчанию 300. Обе переменные токена/чата обязательны для включения; если обе отсутствуют, Telegram выключен. `.env` автоматически не загружается. Новая вкладка терминала не наследует значения, введённые в другой вкладке.

Проверка без Bybit-ключей и ордеров:

```bash
python -m dual_futures_bot --exchange bybit --mode realtime-paper --limit 200 --cycles 1 --state reports/telegram-paper.json
```

Придёт сообщение запуска, затем сводка при успешном получении рынка и сообщение завершения. При ошибке рынка будет сообщение об ошибке. Для непрерывного мониторинга уберите `--cycles 1`. Для Demo используйте команду из руководства Bybit Demo с теми же Telegram-переменными; она может открывать виртуальные биржевые сделки.

## Что приходит

- Запуск, завершение заданного числа циклов, Ctrl+C и ошибка с типом исключения (подробности ошибки остаются локально).
- Сводка: рынок, режим, последняя цена, EMA20/50, тренд, ATR14, ATR/цена, сигнал, фильтр, equity USDT и запрет новых входов.
- Paper: вход/выход, сторона, объём, цена, стоп, модельный чистый PnL при выходе.
- Demo: ID/статус ордера, сторона, запрошенный/исполненный объём, средняя цена, стоимость и комиссия, если Bybit их вернул. Equity и позиция — снимок сверки перед действием текущего цикла; обновятся на следующем опросе.
- Demo-позиция: сторона, контракты, цена входа/mark, плавающий PnL, стоп и плечо, если доступны. Изменение объёма/стороны или исчезновение позиции вызывает отдельное сообщение. Исчезновение позиции не доказывает конкретную причину выхода; точные исполнения и реализованный PnL проверяйте в Bybit.

Время сообщений указано в UTC. Текст полей анализа остаётся на английском; заголовки двуязычные. Токены, ключи и сырой приватный ответ API в сообщения не включаются. Сводка не является полным журналом: сообщения ограничены 4000 символами и могут обрезаться; исходные события сохраняются в локальном state.

## Задержки и сбои

Уведомления отправляются после сохранения торгового состояния. Они зависят от периода опроса и сети, не гарантируют мгновенную доставку. Короткий синхронный запрос может задержать следующую итерацию на время таймаута (3 секунды подключения/3 секунды чтения). Автоматических повторов и очереди доставки нет: при недоступности Telegram сообщение теряется, локально выводится предупреждение, торговая логика продолжает работу. Ошибки настройки переменных до старта останавливают запуск.

Сообщения о запуске/ошибке не означают успешное подключение к Bybit. При жёстком завершении процесса или выключении компьютера сообщение остановки не гарантируется. Telegram не контролирует биржевой стоп и не закрывает позиции.

Если нет сообщений: проверьте Start, chat ID, токен, права отправки и HTTPS-доступ к `api.telegram.org`. Для отключения:

```bash
unset TELEGRAM_BOT_TOKEN TELEGRAM_CHAT_ID
```

Тесты проверяют HTTP-запросы подставными ответами, ограничение сводок, изменения позиции и отсутствие утечки токена в ошибках. Реальная отправка в Telegram в облаке не проверялась: токен и chat ID не предоставлены.

Полный цикл открытия/закрытия позиции между двумя опросами может остаться незамеченным: интеграция отслеживает снимки позиции, а не поток всех исполнений биржи.
