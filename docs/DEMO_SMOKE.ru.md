# Проверка открытия и закрытия Bybit Demo

[English](DEMO_SMOKE.en.md)

Это разовый тест исполнения без EMA/ATR и ожидания графика: рыночный long, затем закрытие фактического объёма через `reduceOnly`. Только Bybit Demo Trading; реальные средства не поддерживаются.

1. Остановите стратегию через Ctrl+C во всех терминалах. Проверьте, что на выбранном инструменте нет позиций и открытых ордеров. Не запускайте другие процессы или ручные сделки на нём во время теста. Тест не блокирует отдельный процесс стратегии автоматически.
2. Активируйте Python-окружение и задайте `BYBIT_DEMO_API_KEY` и `BYBIT_DEMO_API_SECRET` как в основном руководстве. Требуются one-way и линейный USDT perpetual; плечо и маржа остаются настроенными в Bybit.
3. Выполните:

```bash
python -m dual_futures_bot.demo_smoke --execute --max-notional 250
```

Берётся минимальный объём из метаданных биржи с округлением вверх до шага контракта и небольшим запасом над минимальной стоимостью. Его номинал по свежей опорной цене должен укладываться в меньший из 250 USDT и 25% свободного Demo USDT. `--max-notional` можно уменьшить; увеличить выше 250 нельзя. Это потолок расчётного номинала, а не расход 250 USDT и не гарантия цены исполнения; проскальзывание может изменить стоимость. Комиссии и маржа определяются биржей. К примеру, при минимуме 100 USDT и шаге 0.001 BTC цена 80000 даст 0.002 BTC, то есть 160 USDT. Если минимум не помещается в лимит, тест остановится без входа.

Вход сопровождается страховочным стопом на 2% ниже опорной цены. После подтверждения результата входного ордера и появления позиции сразу отправляется рыночное закрытие `reduceOnly`. Между ордерами есть задержка API; это не атомарная операция. Наличие страховочного стопа зависит от принятия Bybit, не заменяет сверку позиции при ошибке.

Ожидаемый результат:

```text
DEMO ROUNDTRIP OK: no position and no open orders for this symbol.
```

В журнале `reports/demo-smoke.json` должно быть `stage: completed_flat`, а в Bybit Demo — исполнения входа и выхода. Точный PnL смотрите на бирже. Этот тест проверяет исполнение и конечное отсутствие позиции, а не прибыльность стратегии. Telegram для него не используется.

## Ошибки и повторный запуск

Перед каждым ордером сохраняются стадия и client ID. Сетевые/неоднозначные ошибки не вызывают повторной отправки ордера. До 10 раз опрашивается только статус уже отправленной заявки и состояние позиции. Если процесс прерван или возникла ошибка, позиция может остаться: немедленно проверьте её, стоп, открытые заявки и исполнения в Bybit Demo, при необходимости закройте вручную.

Журнал создаётся эксклюзивно: существующий файл блокирует повторный запуск. Не удаляйте его ради обхода ошибки. Сначала сверяйте биржу. После полностью завершённого теста и проверки отсутствия позиции/заявок следующий тест можно запустить с новым именем:

```bash
python -m dual_futures_bot.demo_smoke --execute --max-notional 250 --journal reports/demo-smoke-2.json
```

Не запускайте два теста одновременно с разными именами журнала. При отсутствии наблюдаемой позиции после входа (например, быстрый стоп) тест остановится для сверки, не станет повторять вход и не объявит успешное самостоятельное закрытие.

Офлайн-тесты проверили круг вход/выход, reduceOnly, запрет боевого API, наличие чужой позиции, предел объёма и отсутствие повторной отправки после таймаута. Реальный Demo-круг в облаке не выполнен: действующие ключи находятся на компьютере пользователя.
